Frequently asked questions

Connection, availability and rewards.

Is the pool available yet?+

The latest manual snapshot shows initial sync in progress. Stratum access is planned afterwards. Until live monitoring is connected, this site cannot confirm current server availability.

Can I connect over the Internet?+

The local address only works on the pool’s local network. External access requires a public address and an accessible Stratum port. Public access is not configured on this site yet.

Does GitHub host the mining server?+

GitHub Pages hosts the web interface. Bitcoin Core and CKPool run on a separate server. A working website does not mean the mining server is available.

Do I earn a reward for each share?+

No. Shares measure and verify work. Solo rewards depend on finding a valid block accepted by the network. Block rewards have a 100-block maturity period.

Do I need a private key or recovery phrase?+

Never. Only use a Bitcoin BTC receiving address. The form processes it in your browser without saving it or sending it to a service.
