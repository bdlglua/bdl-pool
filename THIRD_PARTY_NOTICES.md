# Third-party design and font assets

## Crypgo

The layout, DM Sans typography, theme palette, card treatment, header and FAQ
presentation are adapted from **Crypgo — Next.js based Crypto Landing Page Template**,
provided by the user. The logo symbol and Bitcoin/arrow SVG assets are taken
from that archive. The source archive remains separate from the deployed site;
the visual components have been adapted to the existing static HTML/JavaScript
site so the Bitcoin monitoring and GitHub Pages deployment remain functional.

Upstream: https://github.com/GetNextjsTemplates/Crypgo-nextjs-tailwind
Author/site: https://getnextjstemplates.com/

The supplied project's README states that the project is under the MIT License.
Its original README, including its license statement and source links, is
preserved in `assets/crypgo/README-original.md`.

## DM Sans

The font is served locally. Its license and original copyright notices are

Font source: https://github.com/google/fonts/tree/main/ofl/dmsans
